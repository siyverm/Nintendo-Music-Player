This app is a music player app that allows a user to search for, favorite, and play music. Song name, album cover image, and audio mp3 file will be stored in a directory that will be called upon when the user clicks on specified song. Opening the app will bring the user to a landing page, allowing them to either search for a song or access their favorites list. To search for a song, a drop down list should appear while the user types their input. Then, with song options available to them on the screen, upon clicking a song, the app will take them to a separate screen to play the song (view as specified earlier). Upon clicking favorites, the user will be directed to a view where they can see all their favorited songs. Same as the search feature, upon clicking a song from the favorites list, the app will take the user to another screen to play the song. While the song is playing, the user has the option to pause or play the audio, as well as click a star button that allows them to save the song to their favorites list if it is not there already.
