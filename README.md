This Android app is a music player application inspired by Spotify designed specifically for Nintendo music. Users can search for songs, play music, and save favorites. Each song’s title, album cover image, and MP3 file are stored locally and loaded when the user selects a song.
When the app opens, users are taken to a landing page where they can either search for music or view their favorites. The search feature includes an autocomplete dropdown that suggests songs as the user types. Selecting a song from the search results or favorites list opens a dedicated playback screen.
On the playback screen, users can play or pause the audio and tap a star button to add or remove the song from their favorites.
